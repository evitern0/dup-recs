# Release Notes: Social Music Group Feed

## 2026-08-02

- Added a group-based social music experience with registration, group creation/joining, email invites, album search, recommendation posts, comments, and member profile views.
- Documented explicit timeline pagination, album snapshot persistence, 255-character validation, and Passport/JWT auth scope in the feature spec.
- Added a monorepo scaffold for the Express API, React frontend, and shared contract package.
- Added API and frontend tests covering auth, group flows, timeline posting, comments, and member history behavior.
